# Where realized prices live, by category

Search realized/sold prices first; asking prices only calibrate retail
replacement. Auction archives usually need the house name + item in a web
search ("heritage auctions philippines 20 pesos victory PMG 63").

## Banknotes
- **Heritage Auctions (ha.com)** — deepest world + US currency archive; results include buyer's premium.
- **Stack's Bowers** — strong US and world paper archives.
- **eBay sold listings** — search with "sold" filter via web search; best for mid-value notes.
- **PMG price guide + population report (pmgnotes.com)** — guide values skew retail; pops show rarity at grade.
- **Banknote World / MA-Shops** — retail asks, use for replacement value.
- Cert lookup: pmgnotes.com/certlookup, pcgsbanknote.com.

## Coins
- **PCGS CoinFacts** — price guide + realized auction records per grade; the single best coin anchor.
- **NGC price guide + auction central**.
- **Heritage / GreatCollections / Stack's Bowers** archives.
- **eBay sold** for bullion-adjacent and mid-value.
- Cert lookup: pcgs.com/cert, ngccoin.com/certlookup.

## Watches
- **WatchCharts** — market price index per reference; tracks real transactions.
- **Chrono24** — asking prices (discount 10–15% for realized); "sold" data behind their index.
- **eBay sold**, **Phillips / Sotheby's / Christie's** results for premium pieces.
- **Bob's Watches** (Rolex) posts buy/sell spreads — a real dealer market.
- Box + papers, service history, and dial originality dominate variance.

## Art
- **artnet / artprice / askART** — auction databases (some paywalled; search "<artist> auction results").
- **Invaluable / LiveAuctioneers** — past-sale archives, free to search.
- **MutualArt** artist pages.
- Auction vs gallery retail spread is wide (often 2x); state both.

## Cameras & lenses
- **eBay sold** — the market.
- **KEH / MPB / UsedPhotoPro** — graded retail, good replacement anchors.
- Collectible (Leica, Nikon rangefinder, Alpa): **WestLicht/Leitz Photographica** auction results.

## Pens
- **eBay sold**, **Catawiki** results, **Peyton Street Pens / nibs.com** retail.
- Modern limited editions: check original MSRP and current dealer stock first.

## Firearms (value research only)
- **GunBroker completed auctions** — the market for modern arms.
- **Rock Island Auction / Morphy** archives for collectible and antique.

## Vehicles
- **Bring a Trailer / Cars & Bids results** — searchable, realized, recent.
- **Hagerty valuation tool** — condition-tiered guide values.
- **Classic.com** aggregates auction results per model.

## Everything else
Start with eBay sold + a web search for "<item> sold price auction"; name
the venue for every number you keep.
