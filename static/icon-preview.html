Notes: Lucide and Phosphor are loaded from public CDNs (unpkg.com) — fine for this preview, not what we'd ship. For production we'd inline the SVG paths directly into templates/base.html so there's no external dependency, no extra HTTP request, and full control over styling. Custom-drawn icons would follow the same inline-SVG pattern. Rifles uses crosshair in both libraries — neither ships an actual firearm icon. We can keep the 🔫 emoji for that one specifically, hand-draw a small SVG, or accept the crosshair mapping.
