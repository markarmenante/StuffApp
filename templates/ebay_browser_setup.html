Use this computer for eBay orders

Saved orders

Connect Chrome or Microsoft Edge on this computer to read an exact eBay order when you choose Import order or Check. It uses your eBay sign-in in this browser.

  1. Download the StuffApp eBay reader and unzip it into a folder you will keep on this computer.
  2. Open chrome://extensions in Chrome, or edge://extensions in Edge.
  3. Turn on Developer mode, choose Load unpacked, and select the unzipped browser-extension folder containing manifest.json.
  4. Return to StuffApp in the same browser, sign in if needed, and refresh this page.

Install once on each computer you use.

Then open a saved order or enter your eBay order number and choose Import order. Keep the StuffApp page open while it reads. If eBay asks you to sign in or complete verification, do that in the eBay tab; the read resumes here.

The reader handles the order you requested. eBay passwords and verification codes stay in eBay. Background Today scans still use their existing connection.
